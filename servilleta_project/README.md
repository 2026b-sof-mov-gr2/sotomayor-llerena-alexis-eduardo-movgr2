# Mock CRUD EPN — Expo

Aplicación académica de gestión visual de aulas construida únicamente con React Native y Expo.

## Ejecutar

```bash
npm install
npx expo start
```

Escanea el código QR con **Expo Go** en Android. También puedes presionar `a` en la terminal para abrir un emulador Android configurado.

## Componentes demostrados

- `FlatList` e `Image` para el listado de aulas.
- `TextInput` y `Switch` para crear o actualizar registros.
- `Pressable` como botón flotante de creación.
- `Modal` de confirmación al eliminar.
- `ToastAndroid` como notificación nativa.
- `useState` para el CRUD en memoria.
